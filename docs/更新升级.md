# 更新升级

> 本文档用于说明如何在私有部署环境中更新 EZtCloud 系统。

> ⚠️ **重要警告：更新升级具有一定风险（可能导致服务中断、配置覆盖或数据异常），操作前请先联系我们确认升级方案。**

## 更新升级命令

在服务器上使用 root 用户执行：

```bash
cd /workspace/isw_v2/deploy/
git pull
./restart.sh
```

## 命令说明

- `cd /workspace/isw_v2/deploy/`：进入部署脚本目录
- `git pull`：拉取最新代码
- `./restart.sh`：重启相关服务，使更新生效

## 建议操作

- 建议在业务低峰期执行更新。
- 更新前建议备份关键数据（数据库、配置文件）。
- 更新后请登录系统检查关键功能是否正常。

## 常见问题

### 1）执行 `git pull` 冲突怎么办？

说明本地有未提交修改。建议先备份本地改动，再处理冲突后重新执行更新。

### 2）执行 `./restart.sh` 失败怎么办？

请检查：

- 当前目录是否为 `/workspace/isw_v2/deploy/`
- 是否有执行权限（可执行 `chmod +x restart.sh` 后重试）
- Docker 与相关容器是否运行正常

如仍失败，请保留终端报错信息并联系技术支持。
