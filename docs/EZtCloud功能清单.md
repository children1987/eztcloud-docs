# EZtCloud 功能清单

> EZtCloud 是物联网设备统一接入平台，可接入各类网关、传感器、执行器、控制器、智能硬件等，实现数据采集、远程控制、数据分析、告警通知、智能联动。同时开放 API 和实时消息，能够和其它系统集成对接。

---

## 一、平台核心能力

### 1.1 项目管理
- **项目隔离**：项目间资产完全隔离，互不影响
- **多项目创建**：支持在单套系统中创建多个项目
- **项目 API**：可通过 API 跨项目进行数据访问和整合

### 1.2 设备类型管理
- **自定义设备类型**：灵活创建任意设备类型
- **功能定义**：为设备类型定义属性、事件、命令
- **消息合法性验证**：自动验证设备上报消息的数据类型和范围
- **从公共产品库创建**：基于厂商预置模板快速创建
- **设备类型配置复用**：规则、任务、告警通知可绑定到设备类型

### 1.3 设备管理
- **直连设备**：WiFi、以太网、蜂窝网络等直接上网设备
- **网关子设备**：通过网关间接接入云平台的设备
- **网关设备**：作为子设备和云平台之间的桥梁，支持协议解析和消息转发
- **多级子设备**：支持设备层级嵌套，如网关→子设备→孙设备
- **设备序列号管理**：唯一标识每一台设备
- **设备在线状态**：实时监测设备连接状态（基于 EMQX 连接状态）
- **设备启用/禁用**：可禁用设备并踢除 MQTT 连接，支持重新启用
- **设备操作记录**：记录所有设备操作日志
- **设备凭证管理**：支持重置 MQTT/TCP 连接凭证（Username/Password/ClientID）
- **设备迁移**：支持将设备从一个设备类型迁移到另一个设备类型（配置迁移）
- **子设备管理**：添加/移除子设备，构建设备层级拓扑

### 1.4 设备组管理
- **自定义设备分组**：创建命名的设备组，组织管理设备
- **设备组排序**：灵活排列设备组顺序
- **批量添加/移除设备**：设备组内设备的批量操作
- **组内设备排序**：设备在组内的位置可调整

### 1.5 厂商与公共产品库

- **厂商管理**：独立于项目的设备生产厂商体系
- **公共产品**：厂商可发布设备类型模板到公共产品库
- **公共产品库**：所有用户可见，支持快速复用设备类型配置
- **产品版本管理**：支持产品固件版本迭代

## 二、设备接入

### 2.1 联网方式支持
- **WiFi**：通过 WiFi 芯片/模组接入
- **以太网**：有线网络接入（10M/100M/1000M）
- **蜂窝网络**：2G / 3G / 4G / 5G / NB-IoT
- **通过父设备**：子设备通过父设备（网关）中转接入
- **通过 DTU**：数据传输单元透传接入

### 2.2 MQTT 接入协议
- **标准设备 MQTT 协议**：内置完整的 Topic 体系
  - 属性上报 `attributes/{username}`
  - 属性下发 `attributes_push/{username}`
  - 属性获取 `attributes_get/{username}`
  - 事件上报 `event_report/{username}`
  - 命令下发 `command_send/{username}`
  - 自定义数据上报/下发 `data/{username}/{identifier}`
- **子设备 MQTT 协议**（新版，支持多级子设备，树形/平铺两种格式）
  - 子设备上线/下线通知 `sub_connect` / `sub_disconnect`
  - 子设备属性上报/下发/获取 `sub_attributes*`
  - 子设备事件上报 `sub_event_report`
  - 子设备命令下发 `sub_command_send`
- **一级子设备 MQTT 协议**（旧版，兼容保留）
- **MQTT QoS**：支持不同服务质量等级
- **TLS/SSL 加密**：支持加密与非加密端口

### 2.3 TCP 接入协议
- **TCP 直连**：设备通过 TCP Socket 接入云平台
- **TCP 注册包**：身份认证机制
- **TCP 心跳包**：连接保活机制
- **支持多种数据格式**：JSON、HEX、Plaintext、Modbus RTU

### 2.4 DTU 接入（MQTT / TCP 透传）
- **MQTT 透传**：DTU 通过 MQTT 协议转发子设备数据
- **TCP 透传**：DTU 通过 TCP 透明转发
- **注册包配置**：兼容各类 DTU 身份认证方式
- **心跳包配置**：支持 TCP 保活
- **远程配置调试**：通过云平台远程下发指令

### 2.5 设备快速连接
- **场景一（自动接入）**：设备上电即自动获取连接信息并接入
- **场景二（扫码添加）**：用户扫码后设备获取连接信息接入
- **连接信息 API**：返回 MQTT / MQTTS / TCP 完整连接参数及 Topic 列表
- **自动创建设备**：设备首次连接时自动创建（场景一）
- **支持 GET / POST**：兼容各类设备 HTTP 能力

### 2.6 Topic 映射
- **自定义 Topic 映射**：将设备原始 Topic 映射到平台标准 Topic
- **序列号占位符**：支持 `{sn}` 动态替换，实现每设备独立 Topic

### 2.7 接入协议选择
- **EZtCloud 标准接入协议**（基于 MQTT）
- **Modbus RTU 透传**（MQTT 或 TCP）
- **其它自定义协议**（通过自定义数据流 + 规则引擎）

## 三、功能定义

### 3.1 属性（Property）
- **属性类型**：
  - 设备上报：仅设备→云平台
  - 云端下发：仅云平台→设备
  - 双向互发：设备↔云平台
  - 云端私有：仅云端读写，不下发到设备
- **数据类型**：
  - Number（数值）：支持单位、精度、最小值、最大值
  - Text（文本）：自由文本
  - Switch（开关量）：支持 true/false、1/0、ON/OFF
  - Enum（枚举）：限定取值范围的文本
  - Object（键值对）：嵌套对象
  - List（列表）：数组类型
- **属性自动验证**：不符合数据类型的消息自动拒绝

### 3.2 事件（Event）
- **事件标识符**：唯一名称标识
- **事件参数**：支持键值对参数定义
- **参数类型验证**：自动验证事件参数数据类型

### 3.3 命令（Command）
- **命令标识符**：唯一名称标识
- **命令参数**：支持键值对参数定义
- **回应参数**：支持设备回复携带回应参数
- **命令实例**：预制命令模板，一键快速下发

---

## 四、规则引擎

### 4.1 规则类型
- **属性上报预处理**：接收设备属性后、更新属性前触发（同步串行）
- **属性上报**：更新设备属性后触发（异步）
- **事件上报**：收到设备事件后触发
- **属性下发预处理**：向设备下发属性前触发
- **属性下发**：向设备下发属性后触发
- **自定义上报**：收到自定义数据流上报后触发

### 4.2 规则操作组件

| 操作组件               | 功能说明                                |
| ------------------ | ----------------------------------- |
| 预处理函数              | JavaScript 云函数，对属性上报做任意加工处理         |
| 向当前设备下发属性          | 设备联动：属性触发→下发属性到本设备                  |
| 向当前设备下发命令          | 设备联动：属性触发→下发命令到本设备                  |
| 向其他设备下发属性          | 跨设备联动：上报触发→下发属性到其他设备                |
| 向其他设备下发命令          | 跨设备联动：上报触发→下发命令到其他设备                |
| 推送到外部 MQTT         | 将设备数据实时转发到第三方 MQTT Broker           |
| 推送到外部 URL（Webhook） | 通过 HTTP POST 将数据推送到第三方接口            |
| OTA 升级检查           | 自动检查并推送固件新版本                        |
| Modbus RTU 解析      | 解析 Modbus RTU 二进制报文生成属性             |
| 属性解析函数             | 自定义 JavaScript 解析任意自定义数据            |
| 云网关解析函数            | 将网关自定义数据分发到子设备                      |
| 云网关解析到子设备属性        | 将网关数据直接转为子设备标准属性                    |
| 自定义云函数             | 通用 JavaScript 处理逻辑（更新私有属性、下发属性/命令等） |
| 向当前设备下发自定义数据       | 对自定义上报数据做出响应回复                      |
| 转发到 EZtCloud 标准协议  | 将自定义数据转为标准协议消息                      |
| 向当前网关上报子设备属性       | 将属性转发到子设备（网关场景）                     |

### 4.3 规则管理
- **设备来源类型**：设备类型级 或 指定设备级
- **属性条件过滤**：设置属性条件，仅符合条件的消息触发规则
- **事件标识符过滤**：事件上报规则按事件标识符匹配
- **自定义数据流标识符过滤**：按数据流标识符匹配
- **规则启用/禁用**：全局启用 + 单设备独立启用
- **规则执行统计**：查看各规则调用次数
- **规则调试日志**：开启调试状态记录每次触发日志

## 五、自定义数据流

### 5.1 数据格式支持
- **Modbus RTU**：二进制 Modbus 报文透传
- **Binary（二进制）**：任意自定义二进制消息
- **JSON**：自定义 JSON 格式消息
- **Plaintext**：纯文本消息

### 5.2 数据流能力
- **MQTT 主题自动生成**：每个数据流自动生成发布/订阅主题
- **TCP 数据流绑定**：将数据流绑定到 TCP 通道
- **数据格式校验**：按设定格式自动验证消息合法性
- **规则引擎处理**：通过规则对自定义数据进行解析、转换、转发

## 六、Modbus 支持

### 6.1 Modbus 寄存器配置
- **IO 寄存器**（开关量）：支持只读/读写，自动生成 01/02/05 功能码
- **数据寄存器**（数值量）：支持只读/读写，自动生成 03/04/06 功能码
- **数据类型支持**：
  - 16 位整数 / 16 位无符号整数
  - 32 位整数 / 32 位无符号整数
  - 32 位浮点数
- **字节序配置**：AB/BA/ABCD/BADC/CDAB/DCBA
- **属性智能转换开关**：一键启用 Modbus 消息自动解析

### 6.2 Modbus 下发任务
- **定时查询任务**：按间隔自动下发 Modbus 查询指令
- **属性下发转 Modbus**：控制台/API 下发属性自动转为 Modbus 写寄存器指令
- **CRC16 校验**：自动生成和验证 CRC16 校验码

---

## 七、定时任务

### 7.1 任务类型
- **属性下发任务**：定时向设备下发属性
- **命令下发任务**：定时向设备下发命令
- **自定义下发任务**：定时向设备下发自定义数据（JSON / HEX / Plaintext）
- **Modbus 下发任务**：定时向设备下发 Modbus 查询指令
- **OTA 升级推送任务**：定时检查并推送固件新版本

### 7.2 定时策略
- **单次定时**：指定时间执行一次
- **间隔定时**：按固定时间间隔执行（如每 30 秒）
- **每日定时**：每天指定时间执行
- **灵活定时策略**：支持多种 Cron 式定时配置

### 7.3 任务管理
- **目标类型**：设备类型级 或 指定设备级
- **手动触发执行**：随时手动运行任务
- **选择执行设备**：可指定任务对全部/部分设备执行

---

## 八、告警通知

### 8.1 告警规则
- **触发条件**：基于设备属性变化设置阈值条件
- **多条件逻辑**：支持「且」(AND) 和「或」(OR)
- **重复次数**：条件连续触发 N 次后进入告警状态
- **持续时间**：条件连续持续 N 秒后进入告警状态
- **告警级别**：普通告警 / 重要告警 / 紧急告警
- **告警状态**：
  - Alerting（告警中）：条件已触发并达到重复/持续要求
  - Pending（待定）：条件已触发但未达到要求
  - Restore（已恢复）：告警条件已消失

### 8.2 通知方式
| 通知方式    | 说明                      |
| ------- | ----------------------- |
| 邮件通知    | 向项目成员注册邮箱发送告警邮件         |
| 短信通知    | 向已认证手机号发送告警短信           |
| 电话通知    | 语音电话告警                  |
| 微信公众号通知 | 向已绑定微信的项目成员推送           |
| 钉钉工作通知  | 向加入钉钉虚拟组织的成员推送          |
| 钉钉群机器人  | 通过 Webhook + 加签方式推送至钉钉群 |

### 8.3 通知管理
- **通知组**：组合多种通知方式，绑定到告警规则
- **通知次数限制**：每日全局上限（默认 1000）和单设备上限（默认 100）
- **告警规则开关**：全局启用 + 单设备独立启用
- **告警历史**：记录所有告警消息，支持按级别/状态/设备搜索
- **告警统计**：项目资源和设备概览中展示告警频次趋势

## 九、OTA 固件远程升级

### 9.1 固件版本管理
- **版本号灵活命名**：支持任意格式版本号（如 `1.0.0`）
- **多模块支持**：一个设备可包含多个可升级模块（如 `main`、`mcu`、`gps`）
- **固件包上传**：支持 `.bin` `.img` `.dav` `.tar` `.gz` `.zip` `.apk` 等格式
- **HTTP / HTTPS 下载**：可选是否使用加密传输
- **启用/禁用版本**：支持版本临时测试或回滚
- **版本不可覆盖**：创建后不支持重新上传，确保版本一致性

### 9.2 升级方式
- **设备轮询检查（Poll）**：设备定期发起 OTA 版本检查请求
- **云端推送升级（Push）**：平台主动下发升级命令
- **批量升级**：同一设备类型下多台设备批量升级
- **定时推送**：通过任务设置在指定时间推送升级
- **灰度升级**：指定部分设备先行升级验证
- **差分升级**：指定待升级版本和目标版本范围

### 9.3 安全机制
- **MD5 校验**：固件包完整性校验
- **版本比较**：云端自动计算设备是否需要升级
- **子设备 OTA**：网关子设备同样支持 OTA 升级

## 十五、开放 API

### 15.1 API 形式
- **HTTP RESTful API**：全面的资源访问接口
- **HTTP Webhook**：事件驱动的 URL 回调推送
- **MQTT API**：实时消息订阅（应用端作为 MQTT 客户端）
- **MQTT @ WebSocket**：浏览器端实时消息订阅
- **Swagger 在线文档**：交互式 API 文档和测试工具

### 15.2 API 能力
- **身份认证**：ProjectToken（推荐，高安全性）/ ProjectSecret（兼容旧版）
- **资源管理**：项目、设备类型、设备组、设备、用户等 CRUD
- **数据访问**：设备属性当前值、历史数据查询
- **设备通信**：属性下发、命令下发、自定义数据下发
- **告警查询**：告警历史和告警规则查询
- **签名认证**：基于 MD5 的请求签名，有效期 2 小时

### 15.3 消息流转
- **MQTT 应用订阅**：实时接收设备属性、事件消息
- **规则引擎流转**：推送到外部 MQTT 或外部 URL
- **数据导出**：对接第三方数据库、BI 分析、AI 训练

## 十七、用户与权限管理

### 17.1 统一身份认证（IAM）
- **OAuth2 认证**：基于 OAuth2 + PKCE 的统一身份认证中心
- **多端登录**：Web PC 端、移动端、SPA 应用均支持
- **JWT Token**：HttpOnly Cookie + Token 双模式
- **Token 自动刷新**：Access Token 过期自动刷新
- **Token 吊销**：登出时主动吊销 Token
- **单点登出**：Webhook 推送登出事件至各子系统

### 17.2 项目成员管理
- **成员角色权限**：Owner（所有者）、Admin（管理员）、App User（应用用户）
- **成员添加/移除**：通过用户名、手机号、邮箱邀请
- **项目邀请**：通过短信/邮件发送注册邀请链接（短链接）
- **成员设备授权**：为成员添加/移除可访问的设备
- **项目所有权转移**：将项目转让给其他用户
