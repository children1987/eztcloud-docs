# 授权

> 私有部署完成后，需要先获取服务器指纹并申请授权码，再在系统中完成授权更新。

## 获取授权码流程（2 步）

## 第 1 步：获取设备指纹

登录 EZtCloud 后，进入以下路径：

- **系统管理** → **系统授权**

在页面的“基础信息”区域，找到并复制：

- **服务器指纹**

请确保复制完整，不要遗漏或添加空格。

## 第 2 步：联系我们获取授权码

将以下信息发送给我们：

- 服务器指纹（必填）
- 客户名称 / 项目名称（建议提供）
- 部署环境说明（生产 / 测试，建议提供）

我们会根据服务器指纹生成对应的授权码并反馈给您。

## 写入授权码

收到授权码后，回到：

- **系统管理** → **系统授权**

在“更新授权”区域：

1. 将授权码粘贴到“授权码”输入框。
2. 点击“保存授权码”。
3. 点击“刷新”确认授权状态是否更新成功。

## 常见问题

### 1）为什么必须使用服务器指纹申请授权？

授权码与服务器指纹绑定，用于确保授权与目标部署环境一一对应。

### 2）更换服务器后授权失效怎么办？

更换服务器通常会导致服务器指纹变化，需要重新获取新指纹并联系我们重新生成授权码。

### 3）粘贴授权码后未生效怎么办？

建议按以下顺序排查：

- 确认授权码是否完整（无缺失、无多余空格）
- 点击“刷新”重新读取授权状态
- 若仍异常，请将服务器指纹与报错信息反馈给我们
