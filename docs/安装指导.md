# 安装指导

> 本文档用于指导您在一台全新 Linux 服务器上完成整套系统部署。内容主要来自原《系统部署指导》，并已按文档中心结构整理。

## 快速安装（推荐）

在一台 Linux 服务器上（**需 root 权限**），可按系统类型直接执行单行命令：

### Debian / Ubuntu（单行安装）

```bash
apt update && apt install -y git && mkdir -p /workspace && cd /workspace && rm -rf isw-helper && git clone https://gitee.com/hotanzn/isw-helper.git isw-helper && cd isw-helper && bash quick_start.sh
```

### CentOS / RHEL / Rocky / AlmaLinux（单行安装）

```bash
yum update -y && yum install -y git && mkdir -p /workspace && cd /workspace && rm -rf isw-helper && git clone https://gitee.com/hotanzn/isw-helper.git isw-helper && cd isw-helper && bash quick_start.sh
```

该脚本将会：

- 自动检测操作系统（支持 Debian/Ubuntu 和 CentOS/RHEL 7+）
- 自动选择包管理器（apt 或 yum）
- 安装基础工具（git、curl、python3）
- 启动部署向导：`python3 deploy_all.py`

### 部署向导交互

上述命令执行后，部署向导将引导您完成如下操作：

- 选择 IP：自动探测可用 IP，让您选择本次部署使用的 IP
- 选择是否安装 EZtView：默认会安装，可选择跳过

## 文档概要

本指南面向最终用户、实施人员、运维人员，介绍如何在一台全新的 Linux 服务器上部署整套系统：

- IAM（认证与用户中心）
- EZtCloud
- EZtView（可选）

## 环境要求

## 系统支持范围（请先确认）

### 当前已支持

- Debian 11（64 位）
- Debian 12（64 位）
- Ubuntu 20.04+（64 位）
- CentOS 7+（64 位）
- RHEL 7+（64 位）
- Rocky Linux（64 位）
- AlmaLinux（64 位）

### 当前暂不支持

- Windows Server
- macOS
- 32 位 Linux 系统
- 已停止维护且无法正常访问可用软件源的旧发行版

> 建议优先使用 Debian 12 或 Ubuntu 22.04 LTS 进行生产部署。

- **Python 版本**：Python 3.6+（推荐 3.7+）
- **权限**：必须使用 root 账户（或 `sudo -i` 切到 root）
- **网络**：
  - 能访问 `gitee.com`
  - 能访问系统软件源（`apt` 或 `yum`）
- **磁盘空间**：建议预留 30GB+
- **默认端口**：
  - PostgreSQL：`55432`
  - IAM：`8081`
  - EZtCloud：`8082`
  - EZtView：`8083`（如启用）
  - Nginx：`80`

## 一次性下载安装并启动部署向导

```bash
mkdir -p /workspace
cd /workspace
rm -rf /workspace/isw-helper

git clone https://gitee.com/hotanzn/isw-helper.git
cd /workspace/isw-helper

python3 deploy_all.py
```

执行后，会启动交互式部署向导：

1. 自动探测服务器可用 IP 并供您选择。
2. 检查并自动安装基础依赖。
3. 准备必要目录和凭证文件。
4. 启动或安装 PostgreSQL 15 容器。
5. 拉取 IAM / EZtCloud / EZtView 的运行时代码。
6. 调用各项目的 `deploy/install.py` 完成容器编排与初始化。
7. 自动创建 IAM OAuth2 客户端并写入凭证文件。

> 如需无人值守，可使用 `--assume-yes`。

## 源码部署（可选）

如需从源码仓库部署，而不是 dist 编译产物仓库：

```bash
cd /workspace/isw-helper
python3 deploy_all.py --repo-mode source
```

可选参数：

```bash
# 指定私钥
python3 deploy_all.py --repo-mode source --ssh-key /root/.ssh/id_ed25519

# 指定源码分支
python3 deploy_all.py --repo-mode source --source-branch dev
```

## deploy_all.py 常用方式

### 全自动部署

```bash
cd /workspace/isw-helper
python3 deploy_all.py --assume-yes
```

### 指定部署 IP

```bash
python3 deploy_all.py --ip 192.168.1.100 --assume-yes
```

### 只部署 IAM + EZtCloud（不安装 EZtView）

```bash
python3 deploy_all.py --only-iam-eztcloud --assume-yes
```

### 自动模式下跳过 EZtView

```bash
python3 deploy_all.py --skip-mcq --assume-yes
```

## 凭证文件说明

部署过程中会生成凭证文件：

- 路径：`/workspace/isw-helper/output/deploy_credentials.json`
- 权限：`600`（仅 root 可读写）

建议部署后将该文件备份到安全位置并严格控制访问权限。

## 完全清理环境（cleanup_all.py）

如需完全卸载并回到初始状态：

```bash
cd /workspace/isw-helper
python3 cleanup_all.py
```

非交互清理（危险）：

```bash
python3 cleanup_all.py --assume-yes
```

额外删除镜像：

```bash
python3 cleanup_all.py --remove-images
```

## 常见问题

### 1）提示不是 root 用户

请先执行：

```bash
sudo -i
```

### 2）CentOS 7 报错：`No module named 'dataclasses'`

推荐先运行快速启动脚本：

```bash
cd /workspace/isw-helper
bash quick_start.sh
```

如仍失败，可手动安装 Python 3.8：

```bash
cd /workspace/isw-helper
bash install_python38_centos7.sh
```

### 3）CentOS 7 yum 源异常（如 mirrorlist/baseurl 错误）

可执行修复脚本：

```bash
cd /workspace/isw-helper
bash fix_centos7_yum_repos.sh
```

若仍异常，请切换到可用镜像源（阿里云 / 腾讯云 / 内网镜像 / vault）后重试。
