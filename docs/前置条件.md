# 前置条件

> 开始安装前，请先确认部署环境满足以下条件。

## 系统支持范围（请先确认）

### 当前已支持

- Debian 11+（64 位，推荐 Debian 13 最新稳定版）
- Ubuntu 20.04+（64 位）
- CentOS 7+（64 位）

### 当前暂不支持

- Windows Server
- macOS
- 32 位 Linux 系统
- 已停止维护且无法正常访问可用软件源的旧发行版

> 建议优先使用 Debian 13 最新稳定版进行生产部署。
>
> Debian 13（amd64 DVD ISO）下载地址：
> [https://laotzu.ftp.acc.umu.se/debian-cd/current/amd64/iso-dvd/debian-13.4.0-amd64-DVD-1.iso](https://laotzu.ftp.acc.umu.se/debian-cd/current/amd64/iso-dvd/debian-13.4.0-amd64-DVD-1.iso)
>
> 或访问 [Debian 官网](https://www.debian.org/) 获取更多支持。

## 环境要求

### 硬件环境

- **计算资源**：
  - 安装 IAM + EZtCloud + EZtView：至少 8 核 CPU、16GB 内存
  - 如不安装 EZtView（仅 IAM + EZtCloud）：至少 8 核 CPU、8GB 内存
- **权限**：必须使用 root 账户（或 `sudo -i` 切到 root）
- **磁盘空间**：建议预留 30GB+

### 网络环境
- 能访问 [gitee.com](https://gitee.com/)
- 能访问系统软件源（`apt` 或 `yum`）
- 开放端口：`80, 433, 5432, 6879, 7883-7886, 8086, 8081-8083, 58084`
