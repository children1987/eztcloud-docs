# 快速安装

> 适合希望“一条命令完成安装”的场景。默认通过 `setup.sh` 自动检测环境并启动部署向导。

## 单行安装命令

### Debian

```bash
apt update && apt install -y curl && curl -fsSL https://docs.eztcloud.com/setup.sh -o setup.sh && bash setup.sh
```

### CentOS

```bash
yum makecache -y && yum install -y curl && curl -fsSL https://docs.eztcloud.com/setup.sh -o setup.sh && bash setup.sh
```

## 部署向导交互

命令执行后，向导会引导你：

- 选择部署 IP（自动探测可用 IP）
- 选择是否安装 EZtView（默认安装，可跳过）

## 如何判断安装成功

安装成功后，终端通常会出现类似以下输出：

```text
============================================================
部署完成
============================================================
EZtCloud (isw_v2): http://192.168.1.189:8082
管理员账号：admin / CyNLFq_uaV0Vdw0pmd4950vXBCx1iZ6c
更多凭证: /workspace/isw-helper/output/deploy_credentials.json
总耗时: 6分钟3秒

祝贺！如需重新安装，可直接重新执行部署引导命令。
root@debian:/workspace/isw-helper#
```

重点关注以下标志：

- 出现“`部署完成`”字样
- 显示 EZtCloud 访问地址
- 显示管理员账号信息
- 提示凭证文件路径（`/workspace/isw-helper/output/deploy_credentials.json`）
- 命令行返回到 shell 提示符（如 `root@debian:/workspace/isw-helper#`）
